# B 端（packages/admin）

Azure 试听支持中文朗读控制，如 `[短停][放慢]先核对证据。[恢复]再作判断。`。暂停和变速按音色实测能力开放，升降音调目前仅对已测的普通 Neural 音色开放。未确认的控制标签会被移除，正文仍可朗读。后台风格名称与玩家候选标签复用共享映射。

Azure 试听文本可写 `[冷静]先校准一个概念。【愤怒】请回答。`，服务端移除标签并按音色能力分段应用风格；不支持时回退配置默认风格或自然风格。`[自然]` 恢复自然，普通括号内容保留。浏览器音色的试听也移除已登记的情绪标签，但只使用本地默认语气。

「提示词管理 → 平台与工具 → 玩家发言与情绪表达」管理所有游戏共用的发言和评委点评提示。可以预览、编辑、恢复默认，点击保存后对新建对局生效。在具体发言的历史请求中展开六层提示词，可在「身份与人设」查看当时使用的文案。

「提示词管理 → 狼人杀」中的「狼人夜聊」可预览首位提议和队友回应。「狼人夜聊 · 配合确认」提供已发言队友被点名的脚本样例，展示他要确认的分工及当晚已发生的狼队对话。

侧栏「视角管理」的「叫号与法官播报」可编辑狼人杀「天黑闭眼」等法官台词及辩论赛「辩题公布」，可按环节、接收范围或关键词筛选。点击播报名称进行编辑。视口宽度达到 1600 CSS 像素时，列表与编辑器左右并排；普通桌面使用弹窗。宽屏下切换条目或筛选时，本页暂存未保存的草稿。编辑时可查看实际替换效果，例如狼人杀座号或辩题与双方观点。「恢复默认」把默认文案放回编辑框，点击「保存」后生效。新开对局读取保存的文案，已开对局与回放沿用各自的记录。两个窗口编辑同一条时，过期的保存会提示重新打开。

「私密行动」按角色列出夜间行动请求，复用提示词目录的编辑、保存与修订号。

在「对局管理」打开一局狼人杀，点击详情页的「对局视角」即可核对本局的事件文字、AI 频道收件人、跟随座位的观战范围和舞台朗读者。可以筛选轮次、阶段及座位，并展开当次 AI 请求读取实际指令和可见历史。导入回放与已删除调用链的对局只展示尚有记录的内容。

后台「提示词管理」（`/prompts`）列出参与模型请求的模板，包括游戏规则、角色身份、阶段任务、平台契约和工具指令。纯主持播报由视角管理维护。来源、用途（如阶段任务、角色身份）可与关键词及「支持模型对比」组合筛选。宽屏（视口宽度 ≥ 1600 CSS 像素）左侧显示目录、右侧直接预览当前模板；普通窗口从列表打开详情抽屉。在详情中选择上下文，并排阅读模板原文与替换后的文本；窄屏上下排列。模板中的变量和能够明确对应的替换值分别高亮。固定文本、参数示例、脚本样例和历史请求在上下文选择器中分别标明来源。

目录里所有模板都可以打开「编辑草稿」。点击「保存」后，新建对局采用保存的模板；工具指令在下一次工具调用生效。目录的「恢复默认」将出厂模板放回编辑框，仍需保存。点击「预览草稿」可查看原版和草稿在同一上下文中替换后的文本。固定文本可直接修改措辞，历史请求缺少原文时可以切换到内置样例。未保存的草稿和实验结果保留在当前模板详情中，关闭详情或切换模板后丢弃。狼人杀「白天发言」和辩论「攻辩提问」还支持「运行对比」，用同一份身份、历史、输出契约和模型参数各调用一次，显示两份回复、格式校验、耗时及可用的用量。历史请求的调试表单可直达目录并定位到当时的请求。

在「玩家管理 → 编辑」绑定模型时可调整温度、输出预算和建议篇幅。留空的字段按人设关键词给出固定建议，手填数值会随玩家保存。建议篇幅用于玩家发言和评委点评的提示词。新建和导入的模型默认输出上限为 8192 tokens，实际请求同时遵守此上限。

在后台「对局管理」工具栏点击「导入对局」打开弹窗，可上传文件、查看模板、校对原文和静音试播。「完成导入」保存并发布当前内容，回到对局记录并选中「导入」来源。没有单独的导入记录页面。跨域部署时设置 `VITE_PUBLIC_APP_URL` 为前台源地址。见[对局剧本导入](./replay-import.md)。

> 状态：P6 完成登录与改密、资源管理、对局列表与详情（调试、阶段图、Trace、完整日志）、创建调试局。

## 技术

React 19 + Vite 8 + react-router 7 + antd 6（中文语言包）。开发端口 `5174`，`/api` 代理到 `http://127.0.0.1:3100`。

## 路由

后台仅支持 PC 浏览器，使用固定左侧导航。点击侧栏底部的用户名可打开账号菜单，修改密码或退出登录。

后台业务页渲染异常时，内容区显示中文提示，侧栏仍可切换页面。点击「刷新重试」重新打开当前地址，或通过「返回对局列表」回到列表。无匹配路由时提示检查链接；登录、改密及后台布局自身的路由异常由外层错误页处理。

## 约定

在「对局管理」打开一局详情，切换到表格下方的「查看调用链」页签可选择调用树、时间线或完整日志，按玩家、节点类型、阶段、请求 ID 或事件序号筛选。完整日志按频道和兜底事件筛选，日志条目和调试阶段路径能直达对应节点。桌面工作区可拖动分隔线调整宽度。左栏调用树或时间线定位节点，右栏可查看事件摘要、同阶段记录和可用的舞台快照。切换节点保留树的展开状态及滚动位置。「节点数据」默认提供阅读视图，按快照展示板子规则、座位阵容、药品、警长和已记录的当晚行动，辩论快照展示辩题与正反方观点。开局和规则结算节点直接打开此视图。也可切换 `react-json-tree` 树形视图和原文，三种模式均可滚动并复制完整节点 JSON。点击模型调用先查看详情，再通过「调试这次调用」打开调试表单。模型用量按有回报的调用统计。查看进行中对局的调用链或调试中的「本局路径」时，每四秒刷新链路摘要，节点详情按需读取。切换页签时，对局信息始终显示在上方。

管理页面通过选中的菜单项标明位置，直接展示筛选、操作和数据。左侧菜单底部的账号菜单提供「修改密码」和「退出登录」。调用链详情在摘要行显示玩法与板子。输入完整事件号（如 `#4`）仅匹配该序号，按玩家搜索可一并找到参与结算的请求。调用树按轮次和阶段访问分组，展示阶段记录数、请求数、实际模型调用次数及最慢单次调用。存在调用失败、校验拒绝、兜底或失败节点时，在父级同步标记。筛选保留命中路径并高亮匹配节点，时间线仍可按顺序核对结果。「只看异常」可与玩家、节点类型、搜索组合。

在「请求对比」中按玩家、座位、阶段、动作或请求 ID 搜索本局的 AI 请求。选择后可在页内编辑当时的玩家人设和当前任务。调用链右侧详情的「调试这条请求」共用同一表单和对比历史。默认使用该请求最近一次成功调用的模型参数，脚本局可选择当前启用的模型。点击「运行对比」后，两版各调用一次同一模型。结果展示两份回复、格式和目标校验、耗时及供应商返回的用量。每条请求可查看最近十次对比，调试结果只写入对比记录。

在「整局调用链」标题旁可单独删除本局调用链。确认后，本局的调用链节点、模型明细、提示词对比记录和本后台的相关内存视图失效，同源已打开的后台标签页也会收到通知。调用链区域显示已删除状态，并直接展示保留的完整日志。

在调用树点击一次模型尝试，或在节点的调用明细点击「调试这次调用」，会预选这次实际调用的模型和采样参数。编辑任务模板时保留动态变量，两次测试都使用该请求当时可见的历史、角色、规则、合法目标和输出格式。「本次草稿」展示修改版的实际任务与可复用模板。点击该记录的「应用这版提示词」并确认后，之后创建的相同玩法、板子对局使用此版本。目录通用版本与调试台板子版本按最近一次适用的保存生效。人设保持原值时沿用各玩家自己的人设，修改时会作为该范围的人设覆盖。已发布的模板属于运行配置，独立于来源调用链。

创建调试局默认开启「自动生成模拟玩家」，按所选板子的最少合法人数生成当局座位。关闭后可按顺序选择已有玩家；关闭脚本化也会切回手动选人。自动阵容支持种子、断点、推进节奏和混沌脚本。

- 登录态：令牌存在 `tokenStore`，账号信息（含是否需改密）以 `GET /api/admin/auth/me` 为准；接口返回 401 时清除令牌回到登录页，返回 40301 时进入改密页。受保护页面与改密页都先等 `auth.loading` 结束再决定跳转，刷新不会闪一下登录页。
- 资源管理复用 `ResourcePage`：每个资源只提供列定义、表单字段、DTO 与表单值的转换，以及可选的搜索字段、下拉筛选（在客户端过滤，资源量级为数十到数百条）、行操作与工具栏操作。业务校验（引用存在、唯一名称、删除受限）以服务端为准，错误信息直接提示。编辑弹窗每次按所点记录预填，取消会丢弃未保存的修改。供应商密钥默认显示掩码，点「更换 API Key」才出现新密钥输入框，留空保留原密钥。
- 桌面资源列表采用固定表格布局和最小宽度，长名称、标识与备用模型省略并可悬停查看；玩家人设完整展示，保留换行并按内容撑高表格行；操作列固定在右侧，按钮保持同排。音色名称与标识分两行显示，模型操作列在有「重新启用」时加宽；玩家将头像与姓名合并，发言设置分行展示。
- 模型与音色共用左右工作区，来源列表与内容区分别纵向滚动，右侧表格按可用宽度排版。首页默认选中第一项，已有来源直达链接选中指定项。
- 模型："测试"真实调用一次模型（`POST /models/:id/test`），结果以提示展示（成功含耗时与是否为 JSON 输出，失败含原因）。被系统因额度耗尽停用的模型显示"额度已用完"与时间，"重新启用"先测试，通过后以 `enabled: true` 保存。
- 音色：云端音色"试听"调用 `POST /voices/:id/preview` 得到 `/api/media/:id` 后播放；浏览器音色直接用 `speechSynthesis` 朗读。"导入默认音色"把内置目录（Azure 63、Mimo 12、浏览器 2）写入，已存在的跳过。
- Azure 音色的风格表单从 `GET /voices/azure/catalog` 读取当前区域的 `StyleList`，显示中文含义及原始风格名，支持搜索与「自然（默认）」（保存为空字符串）。搜索输入显式关闭浏览器自动填充，避免历史输入建议遮挡风格列表。列表也显示中文风格并可按中文搜索。切换来源或修改 Azure 音色名会重置风格为自然。目录加载失败可重试，旧配置未在目录中时标记为原配置并允许保留；目录未找到的音色仅可新选自然风格。Mimo 保留口吻文字输入，浏览器音色不显示风格项。
- 对局详情未结束时每 2 秒只轮询详情；完整日志与 AI 调用（带六层提示词与原始回复，体积大）只在事件进度 `lastSeq` 或状态变化时重新拉取（`progressChanged`），调试指令执行后强制全量刷新。
- 对局信息中的「全屏查看规则图」打开玩法全图。规则画布由 `GET /api/admin/games/:key/phases` 返回的阶段和可能跳转生成，以 100% 定位当前阶段或起点，支持查找、拖动、缩放、全图导航与上下游定位。浏览器限制原生全屏时，查看器铺满页面。
- 调试页的「本局路径图」按轮次绘制调用链中的阶段访问。默认展示最近一轮，每次进入单独成节点，按实际采集顺序连线，点击节点进入对应调用链。没有阶段追踪或调用链已删除时，仅显示日志中有记录的阶段播报及事件号。
- 调试局暂停时可单步、继续、跳过、连续运行。创建调试局可选种子、断点（含"全部阶段"）、推进节奏（连续生成 / 按观众确认）、脚本化，以及只在脚本化打开时可用的"混沌脚本"（弃票 / 放弃 / 自爆 / 非法输出 / 模拟调用失败，用于检查舞台对这些情况的呈现；关掉脚本化会一并关掉它）。列表与详情的类型文案由 `matchTypeLabel` 统一给出：公开 / 调试 / 调试 · 脚本化 / 调试 · 脚本化 · 混沌。
- Trace：每次模型调用按 L1–L6 展示提示词，以及原始响应、解析结果、错误与耗时，可只看失败调用。完整日志包含私密、阵营与 host 频道（兜底记录），可按频道筛选或只看兜底。
- 名为"主持人"的音色用于 C 端主持播报的语音合成。

## 测试

自动测试覆盖日志描述、对局类型文案、令牌与鉴权事件处理（mock fetch）、Trace 面板静态渲染。资源列表按桌面 1440、1920、2560 宽度检查长文本、列宽和操作按钮同排。模型工作区检查按供应商展示、收起再展开、供应商切换后的筛选、分页和滚动保留、新增弹窗及旧入口跳转。导入弹窗检查发布失败重试和统一来源记录，来源过滤另有服务端数据库集成测试。

## 查看玩家的跨局记忆

点击「玩家管理」中的「记忆」，展开「复盘模型调用记录」可逐次查看主备模型、任务领取次数、调用结果、耗时及 token 用量。一次任务尝试多个模型时，每个模型各占一条记录。可以刷新或翻页查看。

在「玩家管理」点击玩家行的「记忆」。可以按玩法和相关玩家筛选，查看自己的对局经验、对他人的观察、修订自哪条记忆和赛后核对结果。展开「来源证据」查看原局、轮次、频道、事件序号和当时的摘录，点击事件号定位原始记录。单独删除过调用链的来源局仍可定位到完整日志。首次正式对局结束后，复盘可能仍在处理，点击刷新可查看进度。

展开「后续决策」可查看每个请求的关联记录。写入提示词表示这次请求具备这条参考信息。只有模型显式返回该记忆编号且行动最终被采纳，才标为「明确引用」。点击决策可跳到调用链请求详情，核对当时的判断和其他候选记忆。

「忘记这条」移除选中的经验。「一键清空记忆」在确认后覆盖当前玩家跨玩法、跨分页的全部记忆，包括筛选隐藏的条目。结果显示已清空的条数和取消的复盘任务数。旧局保留当时使用的快照、回放和调用记录；清空前已开局的对局不再为这个玩家生成赛后记忆，新局可重新积累。
