# 辩论赛规则口径

实现：`packages/games/src/debate/`。

## 人数与身份

- 9–12 人：正方 4、反方 4，其余为评委（1–4 名）。身份按种子随机分配，所有身份公开。
- 正反方按座位顺序编为一辩到四辩。
- 不支持无评委的局：胜负只能来自评委的结构化判定，不再由主持 AI 的点评文本推断。

## 辩题

- 开局参数 `topic: { title, pro, con }` 可指定辩题；不指定时按种子从 `topics.ts` 题库抽取。
- 辩题对所有玩家与观众公开（观众视图 `extra.topic`）。

## 流程

1. 辩题公布（主持播报）。
2. 立论：正方一辩 → 反方一辩，每人不超过 300 字。
3. 攻辩四组，每组一问一答，回答不超过 160 字：
   - 正方二辩问反方二辩
   - 反方二辩问正方三辩
   - 正方三辩问反方三辩
   - 反方三辩问正方二辩
4. 总结陈词：反方四辩 → 正方四辩，每人不超过 300 字。
5. 评委点评：评委依次判定 `pro` / `con` 并点评（不超过 200 字），后面的评委能看到前面的点评。
6. 最佳辩手：评委在 8 名辩手中投票，平票按种子随机决定。

## 胜负

- 评委多数决；票数相同（包括偶数评委对半）记为平局 `draw`。
- 发言或判定不合法时重问 1 次，仍不合法则兜底：发言为"我方坚持己方立场……"，判定为随机一方，并在 host 频道记录兜底原因。
