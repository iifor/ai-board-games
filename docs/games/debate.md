# 辩论赛规则口径

实现：`packages/games/src/debate/`。

## 人数与身份

- 新开对局按公开席位入座。1–4 号为正方，5–8 号为反方，9 号起为评委，9–12 人均可开局。开局页的「随机补满」只从未就座玩家中抽人填空位。
- 正反方按座位顺序编为一辩到四辩。
- 不支持无评委的局：胜负只能来自评委的结构化判定，不再由主持 AI 的点评文本推断。

## 辩题

- 开局参数 `topic: { title, pro, con }` 可指定辩题；不指定时按种子从 `topics.ts` 题库抽取。
- 辩题对所有玩家与观众公开（观众视图 `extra.topic`）。

## 流程

1. 辩题公布（主持播报）。
2. 立论：正方一辩 → 反方一辩。
3. 攻辩四组，每组一问一答。
   - 正方二辩问反方二辩
   - 反方二辩问正方三辩
   - 正方三辩问反方三辩
   - 反方三辩问正方二辩
4. 总结陈词：反方四辩 → 正方四辩。
5. 评委点评：评委依次判定 `pro` / `con` 并点评，后面的评委能看到前面的点评。
6. 最佳辩手：评委在 8 名辩手中投票，平票按种子随机决定。

发言和评委点评都按当前玩家的建议篇幅生成，缺少玩家设置时采用阶段建议 500 字。有效回复按原文入场。

## 胜负

- 评委多数决；票数相同（包括偶数评委对半）记为平局 `draw`。
- 发言或判定不合法时重问 1 次。请求最终失败时该席发言为「过~」，失败评委不投票，全员弃权时按平局结算。host 频道记录失败原因。
