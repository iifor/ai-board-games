# 辩论赛规则口径

实现：`packages/games/src/debate/`。

## 人数与身份

- 新开对局按公开席位入座。1–4 号为正方，5–8 号为反方，9 号起为评委，9–12 人均可开局。开局页的「随机补满」只从未就座玩家中抽人填空位。
- 正反方按座位顺序编为一辩到四辩。
- 不支持无评委的局：胜负只能来自评委的结构化判定，不再由主持 AI 的点评文本推断。

## 辩题

- 开局参数 `topic: { title, pro, con }` 可指定辩题；不指定时按种子从 `topics.ts` 题库抽取。
- 辩题对所有玩家与观众公开（观众视图 `extra.topic`）。

## 流程

1. 辩题公布（主持播报）。
2. 立论：正方一辩 → 反方一辩。
3. 攻辩四组，每组一问一答。
   - 正方二辩问反方二辩
   - 反方二辩问正方三辩
   - 正方三辩问反方三辩
   - 反方三辩问正方二辩
4. 自由辩论由正方先发，两方交替。每方共 1000 字，每位辩手预留 100 字用于首次发言，其余 600 字共享。首次发言或让过后释放该席预留。每次通常 60～120 字，上限为 150 字及该席可用余额，按去除朗读标记后的正文计数。
5. 总结陈词：反方四辩 → 正方四辩。
6. 评委点评：评委依次判定 `pro` / `con` 并点评，后面的评委能看到前面的点评。
7. 最佳辩手：评委在 8 名辩手中投票，平票按种子随机决定。

被明确追问的合资格辩手优先回应。换人替答时，任务指明当前辩手的阵营、立场、原被点名席、提问席及其原话。开放问题优先在未获话权者中抽签，其余按 `1 / (1 + 已获话权次数)` 抽签，获本方推荐者权重加倍。每人最多连续占本方两席。双方连续主动让过即结束，一方总余额不足 20 字时停止分配该方话权，双方都不足 20 字时直接结束自由辩论，剩余字数保留。仅一方有可用话权时由其继续，主动让过即收束。请求重试耗尽记为本轮未能发言，该席暂时让出话权，释放首发预留；同队下一次成功发言后可再次入选。

其他阶段的发言和评委点评都按当前玩家的建议篇幅生成，缺少玩家设置时采用阶段建议 500 字。有效回复按原文入场。

## 胜负

- 评委多数决；票数相同（包括偶数评委对半）记为平局 `draw`。
- 发言或判定不合法时重问 1 次。自由辩论按上述失败规则处理。其他发言请求最终失败时该席发言为「过~」，失败评委不投票，全员弃权时按平局结算。host 频道记录失败原因。
