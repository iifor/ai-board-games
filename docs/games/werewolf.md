# 狼人杀规则口径

实现：`packages/games/src/werewolf/`；测试：`packages/games/test/werewolf/`（各板子的专项测试在 `boards/<key>.test.ts`）。

口径以旧实现（git tag `legacy-final`）的实际行为为默认值；旧实现中明显是 bug 的地方在下表"与旧实现的差异"中单独列出。下文"标准局"各节是所有板子共用的基础规则；各板子的特殊角色见文末"板子"一节。板子规则来源为 `docs/references/werewolf-boards.md`（下称"板子规则表"），优先于旧实现；规则表没写或有歧义时沿用旧实现。下文旧实现文件路径均相对 `packages/server/modules/werewolf/`。

## 身份与阵营

- 12 人：狼人 4；预言家、女巫、猎人、白痴各 1（神职）；村民 4。身份按种子随机分配。
- 狼人互知身份，并共享 `team:werewolf` 频道；其他人只知道自己的身份。
- 一"天"先经历夜晚再进入白天；`round` 即天数，从 1 开始。

## 夜晚

顺序：天黑 → 狼人夜聊 → 狼人击杀 → 预言家查验 → 女巫解药 → 女巫毒药 → 夜间结算（只算出死亡名单，天亮才出局）。

- **狼人夜聊**：存活狼人从种子决定的一人开始按座位号顺时针依次发言，内容只在狼人频道。
- **狼人击杀**：存活狼人投票，只能投存活的非狼人（不能自刀、不能刀队友），可弃票；全部弃票则当晚不杀人；平票按种子随机决定。
- **预言家**：查验除自己外的任意存活玩家，私下得知"好人 / 狼人"，查验记录在之后的身份提示中保留。
- **女巫**：
  - 只有解药未用且当晚有狼刀目标时才被告知刀口，并可选择救人；自救仅限首夜。
  - 同一晚只能用一瓶药：当晚救了人就不能再毒。
  - 毒药可在任意夜晚使用，不能毒自己。
  - 狼刀与毒药是同一人时按毒杀计。

## 第一天：警长竞选

在公布首夜死讯之前进行，首夜死者此时仍可参与。

1. 所有存活玩家决定是否上警。无人上警则没有警长。
2. 候选人按种子打乱的顺序发表竞选发言。
3. 候选人可退水。剩 0 人则没有警长；剩 1 人直接当选。
4. 没上过警的存活玩家投票，可弃票，每人 1 票。
5. 平票：并列者按种子顺序 PK 发言，然后由除 PK 候选人与退水者外的存活玩家投票；仍平票或无人投票则没有警长。

## 白天

天亮公布死讯（按座位号）→ 依次处理每名死者的遗言、开枪、移交警徽 → 警长指定发言顺序 → 白天发言 → 放逐投票 → 放逐结算 → 入夜。

- **发言顺序**：存活警长从左右相邻的两名存活玩家中选一人作为起点，朝远离自己的方向依次发言，警长最后。没有警长时，从昨晚最大号死者的下一位开始顺时针；平安夜则从种子决定的位置开始。
- **放逐投票**：存活且有投票权的玩家投票，不能投自己，可弃票；警长 1.5 票。平票或全部弃票则无人出局，没有 PK。
- **白痴**：首次被放逐时翻牌，免于出局但失去投票权；之后仍可发言，但不能再被投票放逐；夜里被杀照常出局。
- **自爆**：只有狼人在自己的白天发言里可以宣布（部分特殊狼人不能自爆，见各板子）。宣布后其余人不再发言，当天放逐取消，自爆者出局（没有遗言），直接入夜。若自爆者是警长，仍可移交警徽。

## 出局连锁

每名出局者依次处理：遗言 → 猎人开枪 → 移交警徽。

- **遗言**：被放逐者有；白天被猎人带走者有；首夜死亡者（包括首夜死亡的猎人随之带走的人）有；第二夜起的夜间死亡者没有；自爆者没有。
- **猎人**：被狼杀或被放逐时可以开枪带走任意存活玩家，也可以放弃；被毒杀不能开枪。开枪结果公开。猎人在夜里死亡（天亮出局）后开的枪算"夜间开枪"，其余情况（被放逐、白天被带走等）算"白天开枪"，据此决定被枪杀者有没有遗言。
- **警徽**：警长出局时可移交给任意存活玩家或撕毁；兜底为撕毁。

## 胜负

在每个阶段完成后立即判定，按以下顺序：

1. 狼刀锁定：天亮结算时，若只计狼刀就已让神职或村民全部出局，则锁定狼人胜利，同夜被毒的最后一名狼人也不改变结果。
2. 狼人全部出局 → 好人胜利。
3. 神职全部出局或村民全部出局（屠边） → 狼人胜利。
4. 狼人的有效票数（警长 1.5、失去投票权者 0）严格多于好人 → 狼人胜利。

有第三方阵营的板子（`state.thirdParty`，见各板子）：第三方还在争胜（还有存活的核心成员）时，第三方成员不计入第 1–4 条的屠边与票数，好人与狼人都不能获胜；存活玩家全部属于第三方（且核心成员还在）时第三方获胜（`winner` 为 `lovers` 或 `requester`，优先于第 2–4 条）。核心成员一般是全部成员；丘比特的第三方以两名情侣为核心，情侣都出局后第三方失败，剩下的丘比特按普通的非狼人座位参与胜负（不再属于任何胜利一方）。

胜负一旦分出，未执行的遗言、开枪不再进行，直接进入赛后。天数上限为 6：第 6 天结束仍未分胜负时，（第三方以外）有狼人存活判狼人胜利，否则还有第三方成员存活判第三方胜利，否则判好人胜利（`endReason: budget`，不进入赛后环节）。

## 赛后

1. 公布全部身份。从此刻起，所有玩家的提示词与观众视图都能看到全部身份。

观众视图的附加数据（`presentation.view`）：板子名、警长、白痴是否已翻牌，以及昼夜 `period`（按当前阶段是否在夜晚顺序表中判断，供前端切换背景）。
2. MVP 评选：全部玩家（包括已出局者）投票，不能投自己，可弃票。平票时优先胜利阵营（第三方胜利时为第三方成员；丘比特按情侣所在阵营计），再取座位号最小者；无人投票时取胜利阵营中座位号最小者。
3. 赛后发言：全部玩家按座位号依次发言，MVP 最后，每人不超过 180 字。

| 项目 | 旧实现 | 现在 |
| --- | --- | --- |
| 猎人被毒 | 因原因字符串不一致，实际仍可开枪（bug） | 不能开枪 |
| 第二天起警长票权 | 结算时取不到警长，1.5 票实际丢失（bug） | 始终 1.5 票 |

## 板子

板子即引擎的玩法变体（`variant`），在 `boards.ts` 的 `BOARDS` 中登记（定义格式与板子参数在 `boardDefinition.ts`，第三批板子清单在 `boardsExtended.ts`，第四批在 `boardsFinal.ts`）：角色表、人数（`players`，默认 12 人）、底牌（`extraCards`，见"盗贼与底牌"）、板子参数，以及给 AI 的规则说明（由 `roleRules.ts` 按本局角色与板子参数自动拼出：通用规则 + 每个角色的完整规则 + 板子的特殊约定 `notes`；规则层开头的"这是一局 N 人狼人杀"按本局人数）。板子参数（`boardConfigSchema`）：女巫自救口径、是否竞选警长、屠边类别覆盖、狼美人被毒是否带人（`wolfBeautyPoisonLink`）、隐狼口径（`hiddenWolf`）、乌鸦额外票数（`crowVotes`）、黑商口径（`blackMerchant`）。特殊角色各自一个模块（`special/<role>.ts`），在 `roles.ts` 的角色目录中登记阵营、屠边类别与特性（不能自爆、免疫毒药、查验视为好人、不受魅惑、延迟出局等）；本局没有该角色时相关阶段静默跳过。所有板子都有首日警长竞选、自爆与上文的标准规则。

阶段的 `enabled` 只能依据公开信息（本局有没有这个角色、天数）：有标题的阶段会在公开记录中留下"【标题】"，依据私密状态开关的阶段一律不设标题（如大灰狼得知标记、野孩子变狼、狼弟单独击杀、额外技能）。"本局有没有这个角色"（`hasRole`）按板子的牌堆判断（含盗贼板子被抽作底牌的牌）或有座位中途变成该角色，不看座位上实际发到的牌，否则阶段是否出现会暴露底牌。

**法官私下告知的固定信息**：情侣关系、幸运儿等跨越多个夜晚的私密信息写入 `state.seatNotes`（每人只看到自己那一项），与尚未使用的额外技能（`state.gifts`）、额外查验的记录（`state.giftChecks`）一起在规则层末尾展示给本人，不会因为历史记录过长而丢失。

**狼队与离群的狼**：狼人阵营分两种。狼队（阵营 `werewolf`）互相认识、共享狼队频道，一起夜聊与击杀，被封锁时整个狼队受影响。离群的狼（阵营 `lone_wolf`：大灰狼、隐狼）属于狼人阵营——胜负、计票、骑士决斗、混血儿跟随都按狼人算——但不在狼队频道里，看不到夜聊与狼刀投票，也不参与。离群的狼与狼队之间的相识关系在开局写入只有本人可见的 `knownWolves`（大灰狼与狼队互相认识；隐狼视口径而定），身份提示中列出号码。狼刀不能选狼队认识的狼（狼队成员、大灰狼），可以选狼队不认识的隐狼（否则合法目标会暴露隐狼）。

**开枪不翻牌**：有狼王的板子里，猎人与狼王出局时共用标题为"开枪"的阶段，公开记录只写"开枪带走 X号"/"放弃开枪"，被带走者的出局原因为"被枪杀"，不说明开枪者身份（与猎人一样，"开枪"阶段只在有枪的玩家出局时出现）。没有狼王的板子保持"猎人开枪"。出局技能的通用限制：被毒杀、殉情（狼美人、情侣）、被炸弹人炸死的猎人不能开枪；狼王在此之外还不能在摄梦而死、自爆时开枪。

**中途加入狼队**：野孩子变狼、狼弟入队、被种狼感染后只能看到加入之后的狼队频道记录（引擎按 `Seat.teamSince` 过滤），看不到此前的夜聊与刀法。

**盗贼与底牌**（`rules/deal.ts`，引擎 `setup.deal`）：有底牌的板子（`extraCards`）牌堆为角色表加底牌（14 张），开局在允许的两张组合中按种子均匀抽出底牌，其余 12 张再按种子发给座位。底牌不能是（狼人，狼人）、（狼王，狼人）、（盗贼，狼王）、（盗贼，狼人）：最多一张狼人阵营的牌，抽出狼人阵营的牌时盗贼必须在场。底牌写入 `state.thief`，只有盗贼本人可见（规则层也写明两张底牌）。盗贼首夜第一个睁眼：两张中有狼人阵营的牌时直接拿走它（不询问），否则选择一张（"选择自己表示拿第一张"）；拿到的牌改派为盗贼的角色与阵营（拿到狼人牌时加入狼队，狼队频道告知），拿到功能牌当晚即可行动。盗贼牌被抽作底牌时本局没有盗贼，【盗贼】阶段照常出现但没有人行动。盗贼在选牌前算作村民。

**情侣**（`special/lovers.ts`，`state.lovers`）：丘比特连的两人、魅魔与她选的人、鬼魂新娘与新郎。一方出局时另一方殉情：夜里殉情并入当晚死讯（原因 `lover`，与其他夜间死亡不作区分，首夜有遗言）；白天殉情立即公开播报"X号殉情出局。"（原因 `lover_day`，没有遗言）。殉情者不能发动出局技能。同一次出局引发的殉情先于开枪、白狼王带人的结算（殉情触发器声明在开枪之前，触发器链按声明顺序完整执行、互不插队）：情侣出局时开枪带走自己的另一半，另一半按殉情出局，这一枪不再生效（开枪、带人的目标在结算前已出局时一律不再生效）。

**额外技能**（`special/gifts.ts`，黑商的幸运儿、祈求者共用）：预言家的验（查验好人 / 狼人，规则同预言家）、女巫的毒（规则同女巫的毒药，与女巫的药互不影响）各用一次，可以当晚使用也可以留到之后的夜晚；猎人的枪在出局时直接开枪、不翻牌：公开阶段标题为"开枪"，记录只写"开枪带走 X号"，被带走者的出局原因为"被枪杀"，开枪限制与猎人相同（被毒、殉情、被炸死不能开枪，夜间 / 白天开枪的区分相同）。额外技能不覆盖原有技能（例如拿到枪的猎人出局时可以开两枪）。额外技能的阶段不设标题。

**失去技能**（`rules/block.ts` 的 `skillsLost`）：被狼巫诅咒的人从被诅咒的那一晚起、到下一个夜晚到来之前不能发动任何技能（夜间技能、出局时的开枪、白痴翻牌、额外技能），不限神职；魔狼自爆后的那一晚所有神职不能使用夜间技能（只影响夜间技能）。

**神职失去技能**（大树倒下后，`state.godsDisabled`，公开）：所有屠边类别为神职的玩家失去夜间技能（不再收到请求）、猎人不能开枪、白痴不能翻牌，持有额外技能的神职同样不能再使用；非神职的幸运儿不受影响。

**特殊狼人的共同口径**：所有狼人都不能击杀狼人（不能自刀）。狼美人、恶魔、恶灵骑士不能自爆（发言时不提供自爆声明），梦魇可以自爆。恶魔、恶灵骑士免疫女巫的毒药与"夜间开枪"（夜里死亡的猎人开的枪：公开开枪后播报"X号中枪后没有出局"），被放逐等白天出局的猎人开枪照常有效。

**夜间技能封锁**（花蝴蝶抱、梦魇恐惧、企鹅冰冻）：被封锁的人当晚不会收到夜间技能请求；被封锁的是狼人时整个狼队当晚不夜聊、不击杀。封锁后立即私下告知被封锁者"今晚的夜间技能失效"（不论他有没有夜间技能；被梦魇恐惧的猎人改为告知"今晚若被狼人击杀，你将不能开枪"）；封锁到狼人时只告知狼队"今晚有狼人被……"，不说是谁。守卫、禁言长老被封锁的那晚算没有选择，下一晚不受"连续两晚"限制。

### 白狼王&守卫

- **白狼王**：狼人阵营，自爆时可以带走任意一名存活玩家（也可以不带），被带走者没有遗言；被带走的猎人可以开枪。
- **守卫**：每晚守护一名存活玩家，可以自守、可以空守，不能连续两晚守同一人（空守或守卫当晚无法行动时，下一晚不受限制）；被守护者不会被狼刀杀死；同守同救则死亡。
- 与旧实现的差异：旧实现同守同救仍算救活（`effects.ts` 的 `resolveNightEffects`，守护与解药任一生效即免死）；现在按板子规则表"同守同救死"。

### 狼美人&守卫

- **狼美人**：狼人阵营，与狼队一起击杀后单独睁眼，魅惑一名其他存活玩家（可以魅惑狼人，也可以不魅惑），只记在狼美人私密频道。魅惑只管当晚与天亮后的白天：狼美人当晚死亡（如被毒）时，被魅惑者并入当晚死讯一起公布；狼美人在天亮后的白天出局（被放逐、被白天或夜间死亡的猎人枪杀等）时，被魅惑者立即"随狼美人殉情出局"。下一晚入夜后上一晚的魅惑失效。殉情不能被守护或解药挡下；殉情的猎人不能开枪；殉情者的遗言按死亡时间：首夜殉情有遗言，白天殉情没有。不能自爆。本板子的狼美人被毒时仍会带走被魅惑者。
- **守卫**：同"白狼王&守卫"。
- 与旧实现的差异：与旧实现一致（`reducers.ts` 的 `applyWolfBeautyCharm`；`effects.ts` 的 `appendWolfBeautyLinkedDeath` / `applyWolfBeautyLinkedDeath`：魅惑按当天记录、殉情不进遗言队列）；旧实现没有限制狼美人自爆、也没有阻止殉情的猎人开枪（只有被毒不能开枪），现在按板子规则表。

### 恶魔&守卫

- **恶魔**：狼人阵营，狼人行动后单独查验一名好人阵营的存活玩家（必须查验，合法目标不含狼人），私下得知"神职"或"平民"（按屠边类别：神职以外都算平民），查验记录在之后的身份提示中保留。预言家查验恶魔得到"狼人"。免疫毒药与夜间开枪（见上文），不能自爆。
- **守卫**：同"白狼王&守卫"。
- 与旧实现的差异：查验口径与旧实现一致（`reducers.ts` 的 `applyDemonInspect`、`effects.ts` 中毒药对恶魔无效）；旧实现没有实现对夜间开枪的免疫，也没有限制恶魔自爆，现在按板子规则表。

### 恶灵骑士&守卫

- **恶灵骑士**：狼人阵营，与狼队一起击杀，不能自爆，永远不会在夜晚死亡（狼人不能刀狼；免疫毒药与夜间开枪）。反伤全场一次，在夜间结算中、狼刀与毒药之后判定：女巫毒恶灵骑士时女巫当晚死亡（毒药照常消耗）；预言家查验恶灵骑士时预言家当晚死亡，查验结果照常是"狼人"；同一晚既被查验又被毒时只有女巫死亡、预言家不死。反伤对象当晚本就会死亡（如被狼刀）时，不额外记死、也不消耗反伤。反伤死亡与其他夜间死亡一起在天亮公布，首夜有遗言，不能被守护或解药挡下。反伤用掉后，毒药对恶灵骑士仍然无效。
- **守卫**：同"白狼王&守卫"。
- 与旧实现的差异：反伤一次、毒先于验、对象已死不消耗与旧实现一致（`effects.ts` 的 `triggerEvilKnight` 与 `resolveNightEffects` 中的判定顺序）；旧实现在"同验同毒但女巫本就被狼刀"时仍会让预言家反伤死亡，现在按板子规则表"同验同毒则预言家不死"。旧实现没有实现对夜间开枪的免疫、也没有限制自爆，现在按板子规则表。

### 梦魇&守卫

- **梦魇**：狼人阵营，每晚第一个睁眼恐惧一名其他存活玩家，可以不恐惧，不能连续两晚恐惧同一人（只记在梦魇私密频道），之后与狼队一起夜聊、击杀。被恐惧者当晚的夜间技能失效（见上文"夜间技能封锁"）：预言家不能查验；女巫收不到解药与毒药请求，因此看不到刀口也不能用药；守卫不能守护；猎人当晚被狼刀出局时不能开枪（被放逐等其他时候不受影响）；恐惧到狼人则整个狼队当晚不能击杀；恐惧村民没有效果。梦魇可以自爆。
- **守卫**：同"白狼王&守卫"。
- 与旧实现的差异：恐惧目标（不能自选、不能连续两晚同一人、可不恐惧）与封锁范围与旧实现一致（`reducers.ts` 的 `isNightmareBlockingAction` 与目标规则）；旧实现没有实现"被恐惧的猎人当晚被刀不能开枪"，现在按板子规则表。

### 预女猎白混

- **混血儿**：好人阵营，屠边时算作村民，计票时算好人。首夜第一个睁眼，必须选择一名其他存活玩家作为主人（兜底随机）；选择只记在混血儿的私密频道，主人不会得知，混血儿也不知道主人的身份（混血儿与狼人互不可见）。胜负跟随主人的阵营：终局说明中单独写出混血儿随之胜利或落败；对局的 `winner` 仍是阵营胜负。
- 与旧实现的差异：旧实现的混血儿板子是预女猎守混（`werewolf-config/constants.ts` 的 `hybrid-12`），现在按板子规则表用白痴；其余口径与旧实现一致（`reducers.ts` 的 `applyHybridChooseMaster`：阵营不变，结果按主人阵营记录）。MVP 平票时"优先胜利阵营"仍按座位阵营计，不考虑混血儿的跟随。

### 禁言长老&骑士

- **禁言长老**：每晚必须禁言一名存活玩家（可以禁言自己），不能连续两晚禁言同一人。禁言在天亮时与死讯一起公布（"天亮了，……。今天被禁言的是 X号……"），被禁言者当晚死亡则不公布。被禁言者跳过当天的白天发言（因此也不能在发言中自爆），仍可投票、发表遗言；首日的警长竞选在天亮公布之前，不受影响。
- **骑士**：白天发言结束后、放逐投票前可以决斗一名其他存活玩家，全场一次，也可以不发动（不发动只记在骑士私密频道，不暴露身份）。发动时公开翻牌：对方是狼人则该狼人出局，当天放逐取消，直接入夜；对方是好人则骑士出局，白天照常进入放逐投票。决斗出局者（狼人或骑士）都没有遗言；出局者是警长时照常移交警徽。被禁言的骑士仍可决斗。
- 与旧实现的差异：旧实现分成禁言长老局与骑士局两个板子，且都带猎人；现在按板子规则表合成一个板子、没有猎人。禁言必选、可自禁、只影响白天发言，决斗时机与无遗言均与旧实现一致（`aiActions.ts` 的 `elder_silence` 提示、`reducers.ts` 的 `buildDaySpeechOrder` 与 `applyKnightDuel`、`steps.ts` 中 `knight_duel` 位于发言与投票之间、`lastWordsWorkflow.ts` 只给首夜与放逐遗言）。旧实现空过一晚后仍记着上一个禁言目标，现在与守卫一致按"连续两晚"判断。禁票长老变种未实现。

### 禁言长老&潜行者

- **禁言长老**：同上一节。
- **潜行者**：放逐投票中投给的玩家（以最后一轮选票为准；弃票则没有）如果没有被放逐出局（放逐结算后仍存活，包括平票无人出局），潜行者当晚可以暗杀他，全场一次，也可以不发动。这一机会只在当晚有效：不发动、被封锁或当天没有放逐投票（自爆、骑士决斗成功）都会失效。暗杀记在潜行者私密频道，在夜间结算中生效，守护与解药都挡不下（女巫只会被告知狼刀）；天亮与其他死者一起公布，遗言按夜间死亡处理；被暗杀的猎人可以开枪。
- 与旧实现的差异：一致（`reducers.ts` 的 `getStalkerEligibleTarget` / `applyStalkerAssassinate`，`effects.ts` 中暗杀不受守护与解药影响）；旧实现的潜行者局另有猎人、没有禁言长老，现在按板子规则表。

- 角色按板子规则表：魔狼、狼人×3、预言家、女巫、猎魔人、白痴、村民×4（与旧实现 `magic-wolf-demon-hunter-12` 一致）。
- **魔狼**：狼队成员，可以自爆。自爆照常直接进入黑夜，并公开播报"X号是魔狼：今晚所有神职的技能都被封印。"：这一晚所有屠边类别为神职的玩家不能使用夜间技能（`state.godsSealedNight`，在 `canUseNightSkill` 中判断：预言家不查验，女巫收不到用药请求、看不到刀口，猎魔人不狩猎）；封印只管这一晚的夜间技能，白痴的翻牌等白天技能不受影响。魔狼被放逐时，若场上没有其他狼人阵营的玩家存活，他自动翻牌（公开"X号翻牌，身份是魔狼……"），不出局，存活到下一个天亮之后（`state.magicWolfDoom`，公开）：这一晚他照常夜聊、击杀（女巫、猎魔人照常行动，毒杀或狩猎他时他天亮随死讯出局）；天亮公布死讯后（狼刀若已屠边则锁定狼人胜利）他以"血脉之力耗尽"出局，没有遗言。翻牌后到出局前他不能投票（不计入票数比较）；达到天数上限时他视为已出局。
- **猎魔人**：神职，免疫女巫的毒药（毒药照常消耗）。从第二夜起每晚（女巫之后）可以狩猎一名其他存活玩家，也可以不狩猎，选择只记在私密频道。对方属于狼人阵营则对方当晚死亡，否则猎魔人自己当晚死亡（原因 `hunt`），守护、解药挡不下，天亮与其他死者一起公布；判断依据是真实阵营（狩猎不是查验，不受"查验视为好人"影响），魔术师换号后按实际落点。猎魔人当晚另有死因（如被狼刀）时狩猎照常生效。
- 与旧实现的差异：魔狼自爆封印当晚神职、最后一名狼人被放逐时延迟到次日天亮出局并失去投票权与旧实现一致（`reducers.ts` 的 `applySelfDestruct` 设置 `magicWolfSealNightDay`、`getActorsForStep` 过滤神职；`effects.ts` 的 `resolveExileEffects` 与 `appendMagicWolfDelayedDeaths`）；旧实现把魔狼的延迟出局并入次日死讯，现在在死讯之后单独出局；旧实现没有公开封印。猎魔人从第二夜起、狼人死亡 / 好人则自己死亡、免疫毒药与旧实现一致（`reducers.ts` 的 `applyDemonHunterHunt`、`effects.ts` 的 `appendDemonHunterHuntDeath` 与毒药判定）。

### 灵狼

- 角色按板子规则表：灵狼、狼人×3、预言家、女巫、猎人、守卫、村民×4（与旧实现 `spirit-wolf-12` 一致）。
- **夜晚顺序**：板子规则表要求灵狼"在女巫之后、预言家之前"单独睁眼，而标准顺序中预言家在女巫之前，所以有灵狼的板子里预言家改在灵狼之后查验（阶段 `seer_check_late`，标题仍为"预言家查验"；是否启用按牌堆里有没有灵狼判断，公开信息）；其他板子的预言家不变。
- **灵狼**：狼队成员（一起夜聊、击杀，可以自爆）。首夜（标题"灵狼"）必须选择一名好人阵营的存活玩家（合法目标不含狼人）学习技能，学到什么写入法官私下告知的固定信息：
  - 预言家 → 从第二夜起每晚必须查验一名好人阵营的存活玩家，私下得知"神职"或"平民"（与恶魔相同，按屠边类别），记录保留在身份提示中；
  - 女巫 → 一瓶解毒剂（当晚即可使用）：女巫用毒的那一晚，若被毒的不是他自己，私下得知被毒的号码并可以用解毒剂解救，全场一次；解救只抵消女巫的这瓶毒药（毒药照常消耗），被毒者若同时被狼刀则按狼刀死亡；
  - 猎人 → 被放逐出局时可以翻牌带走一名存活玩家，也可以不翻牌：决定只记在私密频道，开枪时才公开"X号翻牌，身份是灵狼（学到了猎人的技能），开枪带走 Y号"，被带走者原因为"被灵狼带走"，按白天开枪有遗言；其他出局方式不能开枪；
  - 守卫 → 从第二夜起每晚可以庇护一名存活玩家（可以庇护自己、可以不庇护，不能连续两晚庇护同一人，空过一晚后不受限制）。被庇护者当晚：不会死于狼刀（不论守卫、解药如何，包括同守同救）与毒药（毒药照常消耗）；夜间出局的猎人开枪打中他时"中枪后没有出局"；预言家（以及额外的查验）查验他得到"无法验出"（`seerResultSchema` 的第三个结果）。庇护不挡猎魔人的狩猎等其他死因；
  - 平民（其他任何身份，含村民）→ 查验时视为好人（`rules/appearance.ts`）。
  - 学到的技能之外的阶段都不设标题（标题只有首夜的"灵狼"），否则会暴露学到了什么。
- 与旧实现的差异：学习对象与技能对应、解毒剂只救当晚被女巫毒的非本人、庇护免疫刀、毒与夜间开枪、庇护者查验无结果、不能连续两晚庇护同一人、学到平民查验为好人与旧实现一致（`reducers.ts` 的 `applySpiritWolfLearn`、`applySpiritWolfAntidote`、`applySpiritWolfGuard`、`resolveSeerFactionResult`，`effects.ts` 中庇护记为守护、解毒剂与庇护使毒药无效、非放逐的开枪打不死被庇护者）。旧实现的灵狼在预言家之后行动，查验结果事后改写（`applySpiritWolfGuard` 修改 `seerCheck.result`，预言家此前已看到原结果），现在按板子规则表让预言家在灵狼之后查验；旧实现学到猎人的灵狼实际无法开枪（`findPendingHunter` 用 `canSpiritWolfUse` 判断，它要求存活，与"已出局"矛盾，属于 bug），现在按规则表在被放逐时可以翻牌带人。

### 幻术师&狼巫

- 角色按板子规则表：狼巫、狼人×3、预言家、女巫、猎人、幻术师、村民×4（与旧实现 `illusionist-wolf-witch-12` 一致）。
- **狼巫**：狼队成员（一起夜聊、击杀，可以自爆）。每晚第一个单独睁眼（标题"狼巫诅咒"），可以诅咒一名好人阵营的存活玩家（合法目标不含狼人），也可以不诅咒，决定写在狼队频道；诅咒过的下一晚冷却（该晚没有请求，再下一晚恢复）。被诅咒者紧接着被私下告知"你被狼巫诅咒了……"，从这一晚起直到下一个夜晚到来之前不能发动任何技能（`state.night.hexed`，见上文"失去技能"）：当晚没有夜间技能请求（预言家不查验，女巫看不到刀口也不能用药，幻术师不能发动幻术），当晚或次日白天出局的猎人不能开枪；下一晚入夜时恢复。
- **幻术师**：神职。每晚（守卫之后、狼人行动之前）可以选择一名其他存活玩家作为幻象，也可以不发动；发动过的下一晚冷却。幻术师当晚在夜间结算中仍要死于狼刀或毒药（守护、解药等已经结算过）时，他不死，幻象代替他死亡，死因不变（被替死于毒药的猎人不能开枪，替死于狼刀的猎人可以开枪）；其他死因不能替代。幻象只记在幻术师私密频道，替死不另行告知（天亮死讯照常公布）。
- 与旧实现的差异：狼巫只能诅咒好人、诅咒后冷却一晚、被诅咒者到下一个夜晚之前不能发动技能（包括开枪），以及幻术师不能选自己、冷却一晚、只替狼刀与毒药，与旧实现一致（`reducers.ts` 的 `applyWolfWitchCurse` 设置 `skillDisabledUntilDay = day + 1`、`isGodSkillDisabled`、`applyIllusionistIllusion`，`effects.ts` 的 `applyIllusionistSubstitution`）；诅咒对狼队可见也与旧实现一致（`views/viewPolicy.ts` 只向狼人展示 `wolfWitchCurse`）。旧实现的狼巫在禁言长老之后、幻术师之前睁眼且不告知被诅咒者，现在按板子规则表"率先"睁眼并由法官提示；旧实现替死者的原因改为"幻象代死"（替死于毒药的猎人仍能开枪），现在沿用原死因。
