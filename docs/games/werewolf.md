# 狼人杀规则口径

实现：`packages/games/src/werewolf/`；测试：`packages/games/test/werewolf/`（各板子的专项测试在 `boards/<key>.test.ts`）。

口径以旧实现（git tag `legacy-final`）的实际行为为默认值；旧实现中明显是 bug 的地方在下表"与旧实现的差异"中单独列出。下文"标准局"各节是所有板子共用的基础规则；各板子的特殊角色见文末"板子"一节。板子规则来源为 `docs/references/werewolf-boards.md`（下称"板子规则表"），优先于旧实现；规则表没写或有歧义时沿用旧实现。下文旧实现文件路径均相对 `packages/server/modules/werewolf/`。

## 身份与阵营

- 12 人：狼人 4；预言家、女巫、猎人、白痴各 1（神职）；村民 4。身份按种子随机分配。
- 狼人互知身份，并共享 `team:werewolf` 频道；其他人只知道自己的身份。
- 一"天"先经历夜晚再进入白天；`round` 即天数，从 1 开始。

## 夜晚

顺序：天黑 → 狼人夜聊 → 狼人击杀 → 预言家查验 → 女巫解药 → 女巫毒药 → 夜间结算（只算出死亡名单，天亮才出局）。

- **狼人夜聊**：存活狼人从种子决定的一人开始按座位号顺时针依次发言，内容只在狼人频道。
- **狼人击杀**：存活狼人投票，只能投存活的非狼人（不能自刀、不能刀队友），可弃票；全部弃票则当晚不杀人；平票按种子随机决定。
- **预言家**：查验除自己外的任意存活玩家，私下得知"好人 / 狼人"，查验记录在之后的身份提示中保留。
- **女巫**：
  - 只有解药未用且当晚有狼刀目标时才被告知刀口，并可选择救人；自救仅限首夜。
  - 同一晚只能用一瓶药：当晚救了人就不能再毒。
  - 毒药可在任意夜晚使用，不能毒自己。
  - 狼刀与毒药是同一人时按毒杀计。

## 第一天：警长竞选

在公布首夜死讯之前进行，首夜死者此时仍可参与。

1. 所有存活玩家决定是否上警。无人上警则没有警长。
2. 候选人按种子打乱的顺序发表竞选发言。
3. 候选人可退水。剩 0 人则没有警长；剩 1 人直接当选。
4. 没上过警的存活玩家投票，可弃票，每人 1 票。
5. 平票：并列者按种子顺序 PK 发言，然后由除 PK 候选人与退水者外的存活玩家投票；仍平票或无人投票则没有警长。

## 白天

天亮公布死讯（按座位号）→ 依次处理每名死者的遗言、开枪、移交警徽 → 警长指定发言顺序 → 白天发言 → 放逐投票 → 放逐结算 → 入夜。

- **发言顺序**：存活警长从左右相邻的两名存活玩家中选一人作为起点，朝远离自己的方向依次发言，警长最后。没有警长时，从昨晚最大号死者的下一位开始顺时针；平安夜则从种子决定的位置开始。
- **放逐投票**：存活且有投票权的玩家投票，不能投自己，可弃票；警长 1.5 票。平票或全部弃票则无人出局，没有 PK。
- **白痴**：首次被放逐时翻牌，免于出局但失去投票权；之后仍可发言，但不能再被投票放逐；夜里被杀照常出局。
- **自爆**：只有狼人在自己的白天发言里可以宣布（部分特殊狼人不能自爆，见各板子）。宣布后其余人不再发言，当天放逐取消，自爆者出局（没有遗言），直接入夜。若自爆者是警长，仍可移交警徽。

## 出局连锁

每名出局者依次处理：遗言 → 猎人开枪 → 移交警徽。

- **遗言**：被放逐者有；白天被猎人带走者有；首夜死亡者（包括首夜死亡的猎人随之带走的人）有；第二夜起的夜间死亡者没有；自爆者没有。
- **猎人**：被狼杀或被放逐时可以开枪带走任意存活玩家，也可以放弃；被毒杀不能开枪。开枪结果公开。猎人在夜里死亡（天亮出局）后开的枪算"夜间开枪"，其余情况（被放逐、白天被带走等）算"白天开枪"，据此决定被枪杀者有没有遗言。
- **警徽**：警长出局时可移交给任意存活玩家或撕毁；兜底为撕毁。

## 胜负

在每个阶段完成后立即判定，按以下顺序：

1. 狼刀锁定：天亮结算时，若只计狼刀就已让神职或村民全部出局，则锁定狼人胜利，同夜被毒的最后一名狼人也不改变结果。
2. 狼人全部出局 → 好人胜利。
3. 神职全部出局或村民全部出局（屠边） → 狼人胜利。
4. 狼人的有效票数（警长 1.5、失去投票权者 0）严格多于好人 → 狼人胜利。

胜负一旦分出，未执行的遗言、开枪不再进行，直接进入赛后。天数上限为 6：第 6 天结束仍未分胜负时，有狼人存活判狼人胜利，否则判好人胜利（`endReason: budget`，不进入赛后环节）。

## 赛后

1. 公布全部身份。从此刻起，所有玩家的提示词与观众视图都能看到全部身份。
2. MVP 评选：全部 12 人（包括已出局者）投票，不能投自己，可弃票。平票时优先胜利阵营，再取座位号最小者；无人投票时取胜利阵营中座位号最小者。
3. 赛后发言：全部 12 人按座位号依次发言，MVP 最后，每人不超过 180 字。

## 与旧实现的差异

| 项目 | 旧实现 | 现在 |
| --- | --- | --- |
| 猎人被毒 | 因原因字符串不一致，实际仍可开枪（bug） | 不能开枪 |
| 第二天起警长票权 | 结算时取不到警长，1.5 票实际丢失（bug） | 始终 1.5 票 |
| 被猎人带走者的遗言 | 因阶段配置错误，实际没有遗言 | 按上文"遗言"规则 |
| 狼人内部平票 | 隐含取座位号最小者 | 按种子随机 |
| 唯一候选人 | 仍开启投票，结果固定为该人 | 直接当选，不投票 |
| 胜负判定时机 | 整个死亡队列处理完才判定 | 每个阶段完成后立即判定，未执行的遗言、开枪跳过 |
| 白天被白狼王带走的猎人开枪 | （重写早期）按夜间开枪处理，被枪杀者没有遗言 | 按白天开枪处理，被枪杀者有遗言 |

## 板子

板子即引擎的玩法变体（`variant`），在 `boards.ts` 的 `BOARDS` 中登记：角色表（合计 12 人）、板子参数，以及给 AI 的规则说明（由 `roleRules.ts` 按本局角色自动拼出：通用规则 + 每个角色的完整规则）。特殊角色各自一个模块（`special/<role>.ts`），在 `roles.ts` 的角色目录中登记阵营、屠边类别与特性（不能自爆、免疫毒药等）；本局没有该角色时相关阶段静默跳过。所有板子都有首日警长竞选、自爆与上文的标准规则。

| key | 名称 | 角色 |
| --- | --- | --- |
| `standard-12` | 预女猎白 | 狼人×4、预言家、女巫、猎人、白痴、村民×4 |
| `hybrid-12` | 预女猎白混 | 狼人×4、预言家、女巫、猎人、白痴、混血儿、村民×3 |
| `silence-elder-knight-12` | 禁言长老&骑士 | 狼人×4、预言家、女巫、骑士、禁言长老、村民×4 |
| `white-wolf-king-guard-12` | 白狼王&守卫 | 白狼王、狼人×3、预言家、女巫、猎人、守卫、村民×4 |

夜晚完整顺序（本局没有的角色跳过）：天黑 → 混血儿选主人（仅首夜） → 禁言长老 → 守卫 → 狼人夜聊 → 狼人击杀 → 预言家 → 女巫解药 → 女巫毒药 → 夜间结算。白天：天亮公布 → 警长指定发言顺序 → 白天发言 → 骑士决斗 → 放逐投票 → 放逐结算。

### 白狼王&守卫

- **白狼王**：狼人阵营，自爆时可以带走任意一名存活玩家（也可以不带），被带走者没有遗言；被带走的猎人可以开枪。
- **守卫**：每晚守护一名存活玩家，可以自守、可以空守，不能连续两晚守同一人（空守或守卫当晚无法行动时，下一晚不受限制）；被守护者不会被狼刀杀死；同守同救则死亡。
- 与旧实现的差异：旧实现同守同救仍算救活（`effects.ts` 的 `resolveNightEffects`，守护与解药任一生效即免死）；现在按板子规则表"同守同救死"。

### 预女猎白混

- **混血儿**：好人阵营，屠边时算作村民，计票时算好人。首夜第一个睁眼，必须选择一名其他存活玩家作为主人（兜底随机）；选择只记在混血儿的私密频道，主人不会得知，混血儿也不知道主人的身份（混血儿与狼人互不可见）。胜负跟随主人的阵营：终局说明中单独写出混血儿随之胜利或落败；对局的 `winner` 仍是阵营胜负。
- 与旧实现的差异：旧实现的混血儿板子是预女猎守混（`werewolf-config/constants.ts` 的 `hybrid-12`），现在按板子规则表用白痴；其余口径与旧实现一致（`reducers.ts` 的 `applyHybridChooseMaster`：阵营不变，结果按主人阵营记录）。MVP 平票时"优先胜利阵营"仍按座位阵营计，不考虑混血儿的跟随。

### 禁言长老&骑士

- **禁言长老**：每晚必须禁言一名存活玩家（可以禁言自己），不能连续两晚禁言同一人。禁言在天亮时与死讯一起公布（"天亮了，……。今天被禁言的是 X号……"），被禁言者当晚死亡则不公布。被禁言者跳过当天的白天发言（因此也不能在发言中自爆），仍可投票、发表遗言；首日的警长竞选在天亮公布之前，不受影响。
- **骑士**：白天发言结束后、放逐投票前可以决斗一名其他存活玩家，全场一次，也可以不发动（不发动只记在骑士私密频道，不暴露身份）。发动时公开翻牌：对方是狼人则该狼人出局，当天放逐取消，直接入夜；对方是好人则骑士出局，白天照常进入放逐投票。决斗出局者（狼人或骑士）都没有遗言；出局者是警长时照常移交警徽。被禁言的骑士仍可决斗。
- 与旧实现的差异：旧实现分成禁言长老局与骑士局两个板子，且都带猎人；现在按板子规则表合成一个板子、没有猎人。禁言必选、可自禁、只影响白天发言，决斗时机与无遗言均与旧实现一致（`aiActions.ts` 的 `elder_silence` 提示、`reducers.ts` 的 `buildDaySpeechOrder` 与 `applyKnightDuel`、`steps.ts` 中 `knight_duel` 位于发言与投票之间、`lastWordsWorkflow.ts` 只给首夜与放逐遗言）。旧实现空过一晚后仍记着上一个禁言目标，现在与守卫一致按"连续两晚"判断。禁票长老变种未实现。
