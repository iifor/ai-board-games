# 移除狼人杀舞台行动状态行

## 目标

狼人杀 v2 舞台不再显示行动状态文字及其 `Activity` 图标。

## 边界

- 保留“天黑请闭眼”等夜间提示。
- 保留“等待下一阶段”等主标题。
- 删除“等待行动”“正在选择”“正在行动”“结果已公布”“本次行动已跳过”等整条状态行。
- 保留角色动作动画、行动者/目标关系和结果内容。
- 上帝视角和玩家视角同步生效，因为二者共用 `InteractionStage`。

## 实现

删除 `packages/client/src/features/werewolf-v2/components/PerspectiveShared/index.tsx` 中的状态行渲染及未使用的 `Activity` 图标导入，并删除 `index.css` 中对应的死样式。不新增组件，不修改服务端、API、数据库或共享类型。

## 验证

- 增加一个最小回归检查，证明所有状态都不再渲染该状态行。
- 运行 C 端类型检查及相关单元测试。
