# 狼人杀 C 端中央内容简化设计

## 目标

中央区域只表达当前阶段和当前人物，实际发言统一由底部字幕条展示，避免同一信息重复出现。

## 展示规则

- 发言阶段中央保留阶段标题、发言者头像和昵称。
- 删除中央的“发言内容”、重复发言文本、“当前发言 / X号玩家”卡片。
- 底部字幕条继续展示实际发言内容。
- “已投票 / 警长”只在投票相关阶段展示，发言阶段隐藏。
- 非发言阶段继续使用现有行动标题、状态、目标和结果展示，不改变游戏状态或事件处理。

## 修改范围

- 仅修改狼人杀 V2 中央舞台组件及必要样式。
- 不修改 WebSocket、工作流、TTS、数据库、共享事件类型和经典版界面。
- 复用现有 `interaction.template` 判断发言与投票场景，不新增状态或依赖。

## 验证

- 添加最小回归测试，确认发言模板不生成重复的中央信息。
- 运行 C 端类型检查、单元测试和生产构建。
