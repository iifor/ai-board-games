# 跨游戏主持人立绘与辩论赛评委单行设计

## 目标

在不改变游戏流程、权限或数据协议的前提下，为辩论赛、狼人杀、谁是卧底三个 v2 舞台建立统一主持人视觉规则，同时解决辩论赛四位评委换行造成的舞台拥挤。

经典版界面保持现状。

## 设计决策

### 评委席

- 有评委时，评委席固定为一行，最多四张卡片。
- 四张卡片在中央区域内等宽分布，不允许换行。
- 昵称优先完整展示；模型名空间不足时使用单行省略。
- 没有分配评委时继续不渲染评委席，不保留空位。
- 保持现有点击查看玩家详情、发言态和 MVP 信息语义。

### 主持人立绘

- 三个 v2 游戏共用一张默认主持人透明立绘。
- 仅在真实主持人发言或阶段播报期间显示主持人立绘。
- 玩家或评委发言时，主持人退出舞台，由现有玩家立绘接管。
- 辩论赛或狼人杀指定 AI 玩家担任主持人时，优先复用该玩家已有透明立绘。
- 谁是卧底继续使用当前默认主持人，不新增主持人选择功能。
- 默认主持人视觉定位为专业、亲和的未来赛事主持人：深色礼服、少量金色细节、正面站姿，不携带阵营色，避免偏向正方或反方。
- 立绘采用短时淡入淡出，不增加常驻动画。

## 各游戏布局

### 辩论赛 v2

- 主持人复用中央发言者立绘区域。
- 立绘位于背景之上、中央环节信息与评委席之下、字幕之下。
- 指定玩家主持与默认主持使用相同尺寸和切换时机。

### 狼人杀 v2

- 主持人复用现有玩家发言者透明立绘槽位。
- 主持人与玩家立绘互斥，不同时渲染。
- 昼夜场景、上帝视角、玩家视角和信息权限保持不变。

### 谁是卧底 v2

- 主持人显示在中央焦点区后方，不遮挡六个玩家席位和阶段信息。
- 玩家依次描述时切换为当前玩家立绘。
- 仅补充前端当前播报者状态，不向公共游戏状态暴露身份、词语或投票明细。

## 舞台层级

各游戏都遵循以下层级，但坐标由各自 v2 样式决定：

1. 游戏背景与场景灯光。
2. 主持人或当前发言玩家立绘。
3. 游戏阶段信息、席位和结果信息。
4. 字幕、弹窗和操作控件。

主持播报结束后立即释放舞台。

## 状态判定

- 当前字幕或事件的 `speakerRole` 为 `host`：显示主持人立绘。
- 存在当前玩家发言者：显示玩家立绘，不显示主持人立绘。
- 系统播报、空闲、等待开局、无可播放文本：不显示主持人立绘。
- 默认主持人资源加载失败：保持舞台为空，不显示破图或占位框。

辩论赛和狼人杀沿用现有播放状态。谁是卧底在现有事件消费过程中保存当前播报者状态，并在确认播放完成时清空；不新增 WebSocket 字段。

## 组件边界

- `PlayerPosterSpotlight` 继续承担三个游戏的透明立绘展示与图片失败降级，不新增主持人组件。
- 共享立绘解析只增加默认主持人资源映射，不承载游戏状态。
- `DebateArena`、`WerewolfArenaV2`、`UndercoverArena` 分别负责本舞台的玩家与主持人互斥切换。
- 各游戏现有控制器或 hook 负责提供当前播报状态，舞台组件不解析原始 WebSocket 事件。
- 各 v2 样式分别负责主持人立绘尺寸、位置和层级。
- Debate v2 样式额外负责评委单行布局。
- 默认主持人立绘作为静态视觉资源加入现有客户端资源体系，不新增组件或依赖。

## 响应式行为

- 辩论赛桌面宽屏：四张评委卡片单行等宽展示。
- 辩论赛中等宽度：保持单行，收紧卡片内边距、头像和文字间距。
- 辩论赛小屏：允许评委席横向滚动，不允许重新换成两行；滚动区域保持键盘和触摸可用。
- 三个游戏的主持人立绘都随各自舞台高度缩放，始终保持完整人物比例，不拉伸、不裁切。

## 无障碍

- 主持人立绘沿用现有实时播报语义，不重复朗读同一段主持人字幕。
- 装饰性立绘图片使用空替代文本；主持人身份由字幕标签表达。
- 评委卡片继续使用现有可点击控件与焦点状态。
- 三个 v2 舞台都尊重 `prefers-reduced-motion`，在减少动态偏好下取消淡入淡出位移。

## 验证

- 增加最小样式测试，锁定评委席不换行、四列等宽和空评委席不占位。
- 为三个 v2 舞台增加最小状态测试，锁定主持播报、玩家发言和系统播报三种互斥显示状态。
- 验证狼人杀玩家视角不会因主持人立绘获得额外信息。
- 验证谁是卧底公共状态不会因主持人立绘暴露词语、身份或完整票型。
- 运行客户端类型检查和相关单元测试。
- 在 Debate v2 实际页面验证四位评委、无评委、指定玩家主持人、默认主持人四种状态。
- 在狼人杀 v2 和谁是卧底 v2 实际页面分别验证主持播报与玩家发言切换。
- 将各游戏参考状态与实现截图按同一视口并排比较，检查遮挡、间距、层级和文字溢出。

## 非目标

- 不修改主持人 AI 行为、声音、提示词或游戏流程。
- 不新增后端接口、数据库字段、共享类型或 WebSocket 协议。
- 不让主持人立绘常驻舞台。
- 不修改经典版界面。
- 不为谁是卧底增加主持人选择功能。
- 不为评委创建新的卡片组件。
- 不改动正反方玩家席位布局。
