# 辩论赛 v2 玩家纵列均匀分布

## 目标

让正反双方各四张玩家卡在侧栏的可用纵向空间内均匀分布，避免卡片集中在顶部，同时保留现有评委席显示逻辑。

## 设计

- 仅调整 `packages/client/src/features/debate-v2/DebateGameV2/index.css` 中 v2 玩家列表布局。
- `.debate-shell--v2 .debate-seat-list` 继续占满侧栏标题下方的剩余高度。
- 四张玩家卡使用 `justify-content: space-between` 首尾对齐、间距自动均分。
- 保留响应式 `gap` 作为矮屏下的最小安全间距。
- 评委席继续由现有 `judges.length > 0` 条件控制：未分配评委时不显示，分配评委后按现有位置与样式显示。
- 不修改玩家卡尺寸、头像、组件结构、经典版辩论赛、API、数据库或共享类型。

## 验收

- 1280×720 与 2048×1024 下，左右各四张玩家卡沿整列均匀分布且完整可见。
- 左右两列的卡片位置与间距一致。
- 无评委数据时不显示评委席。
- 有评委数据时评委席完整可见，且不与玩家卡、主舞台或字幕重叠。
- 客户端类型检查、生产构建、完整单元测试和 `git diff --check` 通过。
