# 辩论赛 v2 玩家纵列间距优化

## 目标

让正反双方各四张玩家卡继续保持纵向等距，但不再撑满整列；将当前视觉间距收窄约一半，同时保持玩家列整体居中，并保留现有评委席显示规则。

## 设计

- 仅调整 `packages/client/src/features/debate-v2/DebateGameV2/index.css` 中 v2 玩家列表布局。
- `.debate-shell--v2 .debate-seat-list` 使用 `justify-content: center`，避免卡片首尾贴近整列边界。
- 四张玩家卡使用 `gap: clamp(52px, 7vh, 66px)` 保持响应式等距：
  - 1280×720 目标间距约 52px；
  - 2048×1024 目标间距约 66px；
  - 对比当前实测约 104–105px 与 133px，缩小约 50%。
- 评委席继续由现有 `judges.length > 0` 条件控制：未分配评委时不显示，分配评委后按现有位置与样式显示。
- 不修改玩家卡尺寸、头像、组件结构、经典版辩论赛、API、数据库或共享类型。

## 验收

- 1280×720 与 2048×1024 下，左右各四张玩家卡等距且整体居中。
- 玩家卡实际纵向间距分别接近 52px 与 66px，允许 2px 的渲染误差。
- 左右两列的卡片位置与间距一致，所有卡片完整可见。
- 无评委数据时不显示评委席。
- 有评委数据时评委席完整可见，且不与玩家卡、主舞台或字幕重叠。
- 客户端类型检查、生产构建、完整单元测试和 `git diff --check` 通过。
