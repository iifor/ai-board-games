# 免费额度模型配置设计

## 目标

复用现有“模型供应商 + 模型”数据结构，将两家控制台中仍有免费额度且当前可调用的模型加入当前 SQLite 配置。

## 范围

- 阿里百炼：保留现有 11 个，新增缺失的 125 个。
- 火山方舟：保留现有配置，新增缺失的 18 个已开通且未暂停模型。
- 不开通或配置 `Doubao-Seed-Evolving`。
- 不新增暂停模型，不清理现有重复项，不修改玩家模型分配。

## 实现

1. 从控制台读取精确模型 Code/Model ID。
2. 以 `provider_id + name` 判断是否已存在。
3. 在单个事务中只插入缺失模型；继承供应商的 Base URL、OpenAI 兼容格式和加密 API Key。
4. 任一写入失败时回滚全部新增记录。

## 验证

- 写入前输出待新增数量：百炼 125、火山方舟 18。
- 写入后确认两个供应商的模型总数和名称集合。
- 分别调用一个新增模型执行最小文本推理测试。
- 不修改源码、API、共享类型、数据库结构或项目运行配置。
