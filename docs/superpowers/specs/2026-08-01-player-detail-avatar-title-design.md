# 玩家详情头像标题设计

## 目标

将共享玩家详情弹窗中位于立绘背后的玩家头像移动到昵称前方，形成“玩家头像 + 昵称”的清晰身份标题。狼人杀、辩论赛和谁是卧底统一生效。

## 设计

- 左侧人物区只展示透明角色立绘，不再叠放圆形玩家头像。
- 右侧标题使用横向布局：圆形玩家头像在前，昵称在后。
- 标题头像使用现有 `PlayerAvatar`，桌面端约 52px；窄屏保持相同语义并允许昵称自然换行。
- 玩家有头像时显示现有头像资源；没有头像时沿用昵称首字回退。
- 昵称继续使用现有 `displayTitle`，不新增品牌图标、模型映射或游戏专属标题。
- 玩家资料、本局信息、关闭操作和无障碍标签保持不变。

## 组件边界

- `PlayerDetailModal` 继续负责共享布局和基础玩家资料。
- 狼人杀、辩论赛和谁是卧底调用方不修改数据契约。
- 游戏适配层仍只传递已有且获授权的本局字段，不扩大身份或存活状态可见范围。

## 状态与降级

- 有立绘、有头像：左侧显示立绘，标题显示头像与昵称。
- 有立绘、无头像：左侧显示立绘，标题头像显示昵称首字。
- 无立绘、有头像：左侧保留现有空人物区域表现，标题显示头像与昵称。
- 无立绘、无头像：标题头像显示昵称首字，不出现破图。

## 验证

- 添加最小结构测试，锁定 `PlayerAvatar` 位于标题区域且不再位于人物立绘区域。
- 运行客户端类型检查和相关单元测试。
- 在共享弹窗实际页面验证桌面与窄屏布局、头像回退、关闭操作和浏览器控制台。
- 将参考截图与实现截图进行同状态对比，确认头像不再被立绘遮挡。

## 非目标

- 不修改人物立绘、玩家头像文件或图片解析规则。
- 不新增后端、API、数据库或共享类型。
- 不调整游戏权限、角色信息或实时/回放流程。
