# AI 玩家角色三视图设计

## 目标与范围

以现有“豆包-三视图”为唯一风格基准，为当前启用且尚无三视图的 12 位 AI 玩家各制作一张独立角色设定图。停用的重复 Claude Code 记录不制作；不修改应用代码、数据库、API 或现有头像。

## 统一视觉规范

- 画面：正方形白底角色设定板，布局与豆包参考图一致。
- 主体：左至右排列正视图、侧视图、背视图；保持同一人物、服装和身体比例。
- 表情：右侧纵向排列平静、开心、生气三张头像特写。
- 风格：精致柔和的 3D Q 版动画角色，约 1:5 头身比，大眼但不过度幼态，圆润面部，干净棚拍光线和柔和阴影。
- 标注：仅使用“正视图”“侧视图”“背视图”“平静”“开心”“生气”六处黑色中文标签。
- 一致性：12 张图共享镜头、比例、光照、材质、留白和标签位置；人物通过轮廓、发型、主色、服装和胸前抽象符号区分。
- 限制：不使用企业 Logo、品牌标准图标、武器、水印、复杂背景或额外人物。

## 生成与交付

- 使用豆包参考图进行风格参考式新图生成，不编辑豆包原图。
- 每位玩家单独生成，文件名采用安全的英文短名，例如 `grok-character-sheet.png`。
- 最终文件统一放入 `artifacts/player-character-sheets/`；不覆盖现有文件。
- 首轮成图优先保证人物一致性和版式完整，再按单一差异进行必要修正。

## 验收标准

每张图必须同时满足：玩家性别和核心气质正确；三视图为同一人物；服装前后结构合理；三种表情可辨；六个中文标签完整；没有额外肢体、人物、Logo、水印或背景元素；缩略图状态下仍能凭配色和轮廓区分玩家。
