# 狼人杀 V2 透明发言人物设计

## 目标

狼人杀 V2 在玩家发言时，只展示透明人物立绘，不再展示人物海报原背景、黑色边框或人物卡片。人物从头部到素材底部完整可见，并与顶部阶段栏、左右席位和底部发言字幕保持独立安全区。

本次覆盖 `packages/client/public/player-posters` 中已有的全部 13 个发言人物。辩论、谁是卧底和经典狼人杀界面保持现状。

## 视觉规则

- 狼人杀日间或夜间场景继续作为唯一舞台背景。
- 发言人物使用带 alpha 通道的透明立绘，水平居中、底部对齐人物安全区。
- 不渲染发言人物的模糊全屏背景、海报卡片、卡片边框和人物标题栏。
- 发言期间隐藏中央交互标题，避免文字压在人物头部或胸前；非发言阶段的交互内容保持不变。
- 顶部阶段栏保持现有位置。
- 底部发言字幕保持现有组件，但人物底部必须位于字幕上方，不发生遮挡。
- 左右玩家席位保持现有布局和点击行为。
- 立绘尺寸使用响应式约束；在 16:9 桌面视口中完整显示，不通过 `object-fit: cover` 裁切人物。

## 素材规范

- 为 13 个现有海报分别提供同名透明 WebP 素材，统一放入 `packages/client/public/player-poster-cutouts/`。
- 每个素材保留原人物身份、服装、姿势、配色和绘制风格，只移除背景。
- 素材四角必须完全透明，人物主体保持不透明，发丝和衣物边缘不得出现明显绿色或杂色边缘。
- 透明素材加载失败时，回退到玩家头像；头像也不可用时使用现有姓名首字母占位，不回退到带背景的旧海报。
- 原 `player-posters` 素材不删除、不覆盖，继续供其他游戏模式使用。

## 组件与数据流

1. `resolvePlayerPoster` 增加可选的素材变体参数，默认仍返回现有 `/player-posters/` 路径。
2. `PlayerPosterSpotlight` 增加可选的透明立绘模式。默认行为不变；透明模式只尝试透明立绘、玩家头像和姓名占位。
3. `WerewolfArenaV2` 在存在发言玩家时启用透明立绘模式。
4. 狼人杀 V2 的局部样式负责人物安全区、透明立绘尺寸，以及发言时隐藏中央交互层。

不新增全局状态、接口、依赖或通用布局系统。

## 预计文件范围

### 新增

- `packages/client/public/player-poster-cutouts/*.webp`：13 个透明人物立绘。
- `tests/unit/playerPosterSpotlight.test.ts`：验证默认海报路径不变、透明立绘路径正确，以及未知人物回退规则。

### 修改

- `packages/client/src/components/PlayerPosterSpotlight/posters.ts`：支持默认海报和透明立绘两种路径解析。
- `packages/client/src/components/PlayerPosterSpotlight/index.tsx`：支持透明立绘模式及其回退顺序。
- `packages/client/src/features/werewolf-v2/components/WerewolfArenaV2/index.tsx`：狼人杀 V2 发言人物启用透明立绘模式。
- `packages/client/src/features/werewolf-v2/components/WerewolfArenaV2/index.css`：移除海报式全屏背景和卡片表现，建立人物、顶部栏和字幕的安全区。
- `docs/project-client.md`：记录狼人杀 V2 发言人物的透明素材约定和回退行为。

## 不在范围内

- 不修改后端、WebSocket、游戏流程、AI 调度、数据库或共享事件类型。
- 不重做左右席位、顶部控制栏或底部字幕组件。
- 不改变辩论、谁是卧底和经典狼人杀的发言海报表现。
- 不新增图片处理运行时依赖；透明素材作为静态资源随前端交付。

## 验收标准

- 13 个已知人物发言时均只显示透明立绘。
- 人物原背景、黑边、海报卡片和中央重复标题均不可见。
- 人物头部不与顶部阶段栏重叠，人物底部不被字幕遮挡。
- 日间和夜间背景下，人物边缘自然，无明显色边。
- 2048×1059、1920×1080 和 1440×810 视口下均不裁切人物主体。
- 透明素材缺失时页面不破版，并按头像、姓名首字母顺序回退。
- 其他使用 `PlayerPosterSpotlight` 的游戏模式视觉保持不变。

## 验证

- 运行透明素材 alpha 检查：确认每个文件包含 alpha 通道、四角透明且主体覆盖率合理。
- 运行新增的最小路径解析测试。
- 运行 C 端类型检查和生产构建。
- 在狼人杀 V2 的日间、夜间发言状态分别进行浏览器截图验收，并与原问题截图并排检查遮挡和裁切。
