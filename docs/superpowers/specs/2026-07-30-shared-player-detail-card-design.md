# 全游戏统一玩家详情卡设计

## 目标

为辩论赛、狼人杀和谁是卧底提供同一套玩家详情卡，以人物形象和基础资料为视觉主体，并按游戏状态及当前视角权限展示可选的本局对局信息。

## 范围

- 覆盖三个游戏的经典版和 v2 展示。
- 复用现有通用 `PlayerDetailModal`、`Player` 类型和透明人物立绘映射。
- 狼人杀专属详情组件改为向通用卡片提供本局字段，不再维护独立视觉结构。
- 谁是卧底玩家席位增加打开详情卡的交互。
- 不新增页面、REST API 或数据库结构。
- 不改变任何游戏的身份可见性和服务端权威规则。

## 卡片布局

卡片采用左右分栏：

- 左侧展示透明全身人物立绘。
- 立绘加载失败时回退玩家头像；头像不可用时回退昵称首字。
- 右侧顶部展示玩家昵称。
- 右侧基础资料展示性别和性格。
- 右侧本局信息展示当前视角允许查看的身份、身份说明和存活/出局状态。

窄屏下改为上下布局，人物形象位于资料上方，内容保持可滚动且关闭按钮始终可用。

## 条件展示

- 昵称使用现有昵称、名称和座位号回退规则。
- 性别或性格未配置时显示“未设置”，保证基础资料结构稳定。
- 各游戏只传入当前已有且允许公开的本局字段。
- 空值本局字段不渲染，不使用 `-` 或“暂无”等占位文案。
- 本局信息没有任何可展示字段时，整个分组不渲染。
- 玩家视角未授权的身份不显示占位提示。

## 各游戏本局信息

### 辩论赛

- 复用现有正方、反方、评委、队长等本局身份文案。
- 展示现有身份说明。
- 不新增比赛统计或从发言内容推导表现标签。

### 狼人杀

- 仅在 `roleVisible` 为真时展示身份和身份说明。
- 玩家快照提供 `alive` 时展示存活或出局状态；出局时可展示已有死亡原因和天数。
- 玩家视角未授权的身份继续整段省略。

### 谁是卧底

- 对局中展示存活或已淘汰状态，淘汰时展示已有轮次。
- 终局揭晓后才显示平民或卧底身份。
- 不在终局前展示私词、卧底身份或任何客户端推断结果。

## 数据与协议

卡片只消费现有 `Player` 快照字段：

- 基础资料：`nickname`、`name`、`sex`、`personality`、头像字段。
- 本局资料：`role`、`roleLabel`、`faction`、`alive`、`deathReason`、`deathDay`。

谁是卧底现有公开玩家快照增加可选的 `sex` 和 `personality` 字段，并从已选择的玩家配置透传。两者不是游戏秘密，实时与回放继续消费同一公开快照；不新增接口。

身份文案继续复用各游戏现有解析。客户端不补全被服务端过滤的信息，也不推导身份、胜负、死亡或技能结果。

## 复用与实现边界

- 使用现有 `resolvePlayerPoster(player, 'cutout')` 解析透明人物立绘。
- 使用现有头像 URL 格式化与回退逻辑。
- 通用 `PlayerDetailModal` 负责统一布局、基础资料和可选本局字段。
- 各游戏只负责组装自身允许公开的本局字段。
- 将玩家详情卡样式归属到通用组件，移除游戏目录中的重复视觉定义。
- 不创建额外卡片抽象，不引入依赖。

## 验收

- 辩论赛、狼人杀、谁是卧底的玩家席位均可打开同风格人物详情卡。
- 已映射玩家展示透明全身立绘，资源失败时按头像、首字顺序回退。
- 昵称、性别、性格可见。
- 辩论赛显示已有阵营/职责与说明。
- 狼人杀上帝视角显示已有身份、身份说明和状态，玩家视角不泄露未授权身份。
- 谁是卧底对局中只显示公开状态，终局后才显示已揭晓身份。
- 缺少本局信息时不出现空分组或占位行。
- 三个游戏的经典版和 v2 在桌面、窄屏下均无溢出。
- 玩家席位和关闭按钮支持键盘操作，弹窗保留现有关闭行为。
- 共享类型、谁是卧底公开投影和详情字段条件展示具备针对性测试。
- 共享类型检查、客户端类型检查、生产构建和差异格式检查通过。
