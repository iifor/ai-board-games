# Edge TTS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add Edge TTS as an optional server-side voice provider with MP3 output, word-boundary subtitles, existing cache integration, and browser-speech fallback.

**Architecture:** A focused `edge.ts` adapter translates the existing `VoicePackage` contract into `@andresaya/edge-tts` calls and returns the same media shape as Azure and Mimo. Existing service dispatch, cache, game-socket media preparation, client audio playback, and ACK behavior remain authoritative.

**Tech Stack:** TypeScript, Node.js, `@andresaya/edge-tts`, Node test runner, pnpm.

## Global Constraints

- Provider id is exactly `edge`.
- Output is MP3 with MIME type `audio/mpeg`.
- `EDGE_TTS_TIMEOUT_MS` defaults to 15000 milliseconds.
- Edge failure must not fail the game workflow; existing browser TTS fallback remains final.
- Do not modify REST API, WebSocket envelopes, database schema, shared event types, or client playback code.
- Preserve all unrelated uncommitted workspace changes and stage only task-owned paths.
- Do not add retry queues, circuit breakers, automatic provider switching, or streaming playback.

function isEdgeVoice(voice: VoicePackage | null | undefined): boolean {

interface EdgeClient {
  synthesize(text: string, voice: string, options: Record<string, string>): Promise<void>;

  getWordBoundaries(): Array<{ offset: number; duration: number; text: string }>;
}

type EdgeClientFactory = () => EdgeClient;

async function synthesizeEdgeVoice(
  voicePackage: VoicePackage,
  text: string,
  createClient: EdgeClientFactory = createDefaultEdgeClient,
