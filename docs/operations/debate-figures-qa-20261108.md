# 辩论赛人物席位验收（2026-11-08）

## 展示与交互

- 桌面正反方各四名辩手，按辩位组成 2×2 阵容；两侧队伍跨舞台两行使用完整高度，评委席位于中央下方。
- 完整角色头顶显示正方/反方及一至四辩，脚下为编号站台，自定义名字置于下方。正方青蓝、反方红、评委金色。
- 当前发言席位亮起阵营色聚光灯，其他人物轻微压暗；中央继续使用现有发言立绘和文字。人物无外围边框，发言不改变占位。
- 原有鼠标悬浮与键盘资料入口保留，资料不需要点击。手机使用同一入口中的紧凑头像形式；逐句字幕随文档排在阵容下方，避免盖住立场与头像。
- 内置人物沿用现有素材，自定义人物沿用头像与缺图占位；没有新增图片或动画依赖。

## 验证

- 前端 14 个测试文件、159 项测试通过；新增五项用例覆盖一至四评委的阵容、辩位顺序、人物素材、悬浮入口、发言灯光和自定义头像。
- 九人和十二人真实脚本化调试局均完成，分别为 22 和 25 个事件；模型调用均为 0。调试局保持静音，不调用云端 TTS。
- 在 1920×1080、1600×960、1280×720、1024×768、900×600、768×1024、390×844、320×650 检查两种阵容，共 16 次布局检查：没有横向溢出、席位相交或席位侵入中央舞台。低矮桌面允许纵向浏览，手机切换紧凑头像。
- 初轮实际画面发现公共卡片内边距压缩立绘，已修正样式优先级，并将评委席移至独立的中央下方区域。手机截图发现原固定字幕覆盖立场，已改为页面内排版。
- 内置浏览器保存并查看了桌面主持播报、十二人发言、手机完整页面截图。Ego 截图接口超时，布局与交互检查继续使用 Ego，画面检查使用内置浏览器。
- 悬浮资料与键盘 Tab 切换正常；桌面发言席位边框宽度为 0、卡片阴影为 none，中央人物和对应席位聚光灯同步。
- 十二人真实调试回放以 3× 静音完整播放到终局，观察到全部 12 个席位依次发言/点评；聚光灯始终只对应当前席位，朗读采样异常与音频资源请求均为 0。
- 缺图故障注入后正常退回公开头像，人物占位不变；长名字保持省略和固定占位。减少动态效果时仍显示静态聚光灯，过渡由全局规则缩短到 0.01ms。共用人物样式抽出后，狼人杀十二个席位的形象、站台和无边框表现通过浏览器回归。
- 前端 TypeScript 检查、Vite 生产构建和 `git diff --check` 通过（Git 仅提示 LF/CRLF 转换）。

本地证据位于 `tmp/debate-figures-20261108/`。截图以 `speaking-twelve.png`（桌面）和 `mobile-final.png`（手机）为准。实体手机与人工长时间观看尚未验证。
