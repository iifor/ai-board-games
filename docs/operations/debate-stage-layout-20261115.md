# 桌面辩论舞台分区优化

根据页面截图，将相互遮挡的记录和阵容分开，并调整中央人物与评委席的比例。

- 两侧记录面板保留等高、居中与黑色半透明底色，舞台阵容在两面板之间布局，间隔 16px。
- 1440px 等较窄桌面窗口的顶部信息栏换行时，记录面板额外为其留白；正反方和立场文字不再被记录覆盖。
- 中央立绘使用 84% 高度和 64% 背景层不透明度，减少与正文竞争；中央完整发言保持原有适配字号逻辑。
- 评委席改为同排自适应列，人物高为 140–260px，模型名完整换行展示。
- 逐句字幕保留原有功能，并单独预留底部空间，避免与评委重叠。

## 第二轮：标签贴近人物，正文与资料卡分开

根据后续截图，再次调整中央区域和资料卡：

- 中央人物改为正文上方独立区域，高度为 `clamp(112px,20cqw,220px)`，正文从人物下方开始，互不重叠。
- 辩论正文保留全文和段落，双空行改为较紧凑的段间距，正文行高 1.45、字重 600。长文本继续自动缩字、整段展示，不滚动。
- 辩手卡片按自身列宽和窗口高度安排人物，不再把人物占位拉满整行；辩位标签贴近人物，姓名完整换行。
- 人物资料不再贴着席位向中央弹出。正方与评委资料停靠左侧记录区，反方停靠右侧记录区。两侧记录的开关状态不受影响，关闭资料后仍可看到原记录。资料层位于记录之上，保持中央正文可见。
- 侧边资料给指针跨区预留 450ms；ArrowDown 将焦点移到可滚动的资料内容，Escape 关闭资料。
